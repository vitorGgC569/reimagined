# OxtaCore - Protótipo v2.1

Este diretório contém a versão congelada e validada do protocolo OXH v2.1.

## Como usar
Para rodar este protótipo, certifique-se de estar no diretório raiz e ajustar os imports se necessário, ou mover este pacote para o `PYTHONPATH`.
