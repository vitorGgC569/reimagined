# Tiled head/loss integration

`NSOS_HEAD_CCE=1` selects the exact, unfiltered training head policy
`exact_unfiltered_bitlinear_row128_vocab256_recompute_v1`. Unset/false preserves
the previous logits route and fingerprint. Unknown boolean values fail closed.
The active policy is sealed into Trainer's execution identity and checkpoints.

The design follows the loss-memory motivation in the
[original CCE implementation](https://github.com/apple-aiml-research/ml-cross-entropy),
including its explicit distinction between filtered and exact gradients.
This implementation uses native NSOS Tensor/BLAS and HIP/CUDA glue; it is not a
Triton port and makes no upstream throughput claim.

The model produces normalized hidden states with a one-shot training ticket.
BitLinear computes stable online vocabulary LSE and target logits, then
recomputes each tile for its VJP. No full tokens-by-vocabulary plane is saved.
The default maximum live logit tile is 128*256 FP32 elements (128 KiB).
Pre-affine outputs and gradients have similarly bounded tile dimensions;
parameters, input activations, effective QAT weights and their gradients still
scale with their normal dimensions. The maximum tile element count is returned
by the standalone operation. Temporary BLAS workspace is not included in that
count; measure the pool/driver peak to assess whole-model memory.

Contiguous weight/affine tiles use owned storage views rather than copies.
Reference CPU/GPU, CPU packed STE, supported GPU QAT, RMSNorm, magnitude, bias,
reference/CPU LoQA and CPU Hadamard/Tequila gradients retain their existing
semantics. GPU non-reference paths lacking a supported original backward are
rejected explicitly. QAT uses the full weight absmean scale, never a per-tile
scale. Master parameters remain FP32 and QAT saturation clipping is unchanged.

Weights are published through the existing Parameter accumulation API. The
model folds the head gradient into the canonical tied embedding weight once.
Ignored head rows are cleared before projection, so even poisoned unused input
rows cannot contaminate dW through zero times NaN. This does not detach prompt
tokens in the trunk: their contextual gradients still flow from supervised
answer tokens through the mixers. Empty masks have zero loss and gradient.

Trainer common-token, accumulated-microbatch, heterogeneous SFT and batched-loop
paths use the same operation. Their existing denominators remain authoritative:
token mean for pretraining, answer-length normalization followed by sample mean
for SFT. The gradient multiplier includes loss scaling before publication.
Optional logit L2 and repetition unlikelihood use the same masks and previous
four distinct answer-token window, EOS exclusion and probability cutoffs as the
existing objectives. Three device loss scalars carry CE/RUL/L2 separately.
Inference/generation retains explicit logits.

Validation source: `tests/test_tiled_head_loss.cpp`, independent dense FP64
softmax/objective oracle, forward/VJP comparisons, exact finite differences,
CPU packed and GPU QAT, adapters, mask poison, bounded tiles, tied-weight Trainer
step/SFT and execution identity. GPU registration is fail-closed. Build and
execution results will be recorded against the final integrated source revision.

The tile scheduler currently recomputes multiple BLAS contractions. A smaller
logits allocation is not proof of faster training or lower whole-model peak.
GPU remains experimental. Benchmark and held-out quality/cost gates remain open
until the final implementation has been built, tested and measured.

The first isolated CPU build passed the CCE oracle/gradient/mask/STE/adapter,
finite-difference and tied-head Trainer/SFT cases. It also exposed a preexisting
packed BitLinear batching bug: the integer adapters read the first two axes of
a [batch,time,features] tensor as [rows,features]. The shared packed projection
now explicitly flattens the leading axes before dispatch; reference/GPU paths
already did so. The CCE test exercises this with distinct batched rows. Final
CPU/HIP regression is still required against the combined implementation.
